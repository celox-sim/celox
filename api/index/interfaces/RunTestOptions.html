passOverrides? ​

optional passOverrides?: string[]

Defined in: packages/celox/src/types.ts:403

Per-pass overrides applied on top of optLevel. Each entry: "+sir:<pass_name>" to enable, "-sir:<pass_name>" to disable.

Valid SIR passes: store_load_forwarding, hoist_common_branch_loads, bit_extract_peephole, optimize_blocks, split_wide_commits, commit_sinking, inline_commit_forwarding, eliminate_dead_working_stores, reschedule, coalesce_stores, gvn, concat_folding, xor_chain_folding, vectorize_concat, split_coalesced_stores, partial_forward, identity_store_bypass, tail_call_split, derived_edge_units (generated units for the edges of gated and divided clocks; "-sir:derived_edge_units" walks their plans instead, which builds faster and ticks slower), partitioned_settle (settle only the partitions of the combinational logic whose inputs changed; off unless enabled with "+sir:partitioned_settle")

Example ​

ts
["-sir:reschedule", "+sir:gvn"]

threads? ​

optional threads?: number

Defined in: packages/celox/src/types.ts:460

Simulation threads, including the calling thread. Default: 1.

With more than one thread, phases with enough independent work get lane-partitioned alternatives that run concurrently; each is kept only when it measures faster than its sequential version. Results are identical to sequential simulation. Use at most the number of physical cores.

tier? ​

optional tier?: boolean

Defined in: packages/celox/src/types.ts:471

Run tiered: execution starts on the interpreter immediately while the host's compiled tier is prepared on a background thread, and the simulation adopts it at the next safe point after compilation. Default: false (compile up front before the first tick).

Honored by Simulator.create, fromSource, and fromProject; rejected by fromFrontendArtifact, the time-based Simulation factories, and addons without tiered support (e.g. WASM).
