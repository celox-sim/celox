coverage() ​

coverage(): CoverageReport

Defined in: packages/celox/src/simulation.ts:526

The covergroup coverage of the simulation (IEEE 1800-2023 clause 19) as of the last completed step: every covergroup type that has an instance, with its coverpoints, crosses, bins and hits, for the type and for each instance. Each call builds the report; reading it changes nothing and advances no time. A design without covergroups, any Veryl design included, reports coverage 100 and no covergroup.

Counts are JavaScript numbers, exact up to Number.MAX_SAFE_INTEGER.

reset() ​

reset(signal, opts?): void

Defined in: packages/celox/src/simulation.ts:672

Assert and release a reset signal.

The active level is determined automatically from the Veryl type:

  • reset / reset_async_high / reset_sync_high → active-high (1)
  • reset_async_low / reset_sync_low → active-low (0)

For sync resets (with an associated clock from FfDeclaration), advances activeCycles worth of the associated clock's period using runUntil. For async resets without an associated clock, duration must be specified. An explicit duration overrides cycle-based calculation for either type.

waitForCycles(clock, count, opts?): number

Defined in: packages/celox/src/simulation.ts:625

Wait for count rising edges of the given clock.

Detects actual posedges by reading the clock signal directly from the shared buffer (clock ports are excluded from the DUT proxy). In a four-state simulation, a change from x or z to 1 and from 0 to x or z is a posedge too (IEEE 1800-2023 Table 9-2). The clock must have been registered via addClock.
